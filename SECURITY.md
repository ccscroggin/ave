# Security

Please report security problems privately, not in a public issue. Use
GitHub’s private vulnerability reporting: the **Security** tab, then
**Report a vulnerability**.

Things we especially want to hear about:

- Any way to publish a guide without a reviewer’s approval.
- Any way to read or reuse someone else’s review or owner link.
- Anything that exposes a person’s information.

Review and owner links are secrets. If you think yours has been shared,
ask the maintainer to turn it off and issue a new one.
